# Plume

Лёгкое рабочее окружение для Wayland на базе `labwc`, `waybar`, `mako` и нативных компонентов на C / GTK4 (`gtk4-layer-shell`). Разрабатывается для [Ouvert Linux](https://github.com/etern4llyfunny/ouvert-linux).

## Сборка и запуск (вложенная сессия)

    make
    ./run-nested.sh

## Зависимости

`labwc`, `waybar`, `mako`, `swaybg`, `gtk4`, `gtk4-layer-shell`, `pkgconf`, `gcc`, `thunar`
