# Plume

Рабочее окружение Wayland для [Ouvert Linux](https://github.com/etern4llyfunny/ouvert-linux).
Текущая версия использует **Wayfire**, Waybar, Mako и собственные компоненты
на C / GTK4: лаунчер, док, настройки и меню питания. Файлы `config/labwc/`
сохранены от раннего прототипа; текущая сессия их не использует.

## Сборка пакета Arch Linux / CachyOS

На хосте Arch Linux / CachyOS, в каталоге репозитория, от обычного пользователя:

```sh
makepkg -si
```

Нужны инструменты `base-devel`. Зависимости перечислены в `PKGBUILD`.
Рецепт собирает архив тега `v0.1.0-beta1`, а не незакоммиченные исходники
рабочего каталога. Ревизия пакета 2 добавляет зависимости и ярлык настроек.
После установки выйди из текущей сессии и выбери **Plume** на экране входа.

## Проверка изменений из рабочего каталога

На хосте с установленными зависимостями, внутри текущей графической сессии:

```sh
make
PLUME_ROOT="$PWD" ./run-nested.sh
```

`PLUME_ROOT` явно выбирает ресурсы рабочей копии, даже если пакет Plume уже
установлен. Вложенный запуск подходит для проверки интерфейса; блокировку
экрана, вход в систему и аппаратные клавиши проверяй в отдельной сессии Plume.

## Основные сочетания

| Действие | Клавиши |
| --- | --- |
| Лаунчер | Super+D |
| Терминал Kitty | Super+Enter |
| Файлы | Super+E |
| Настройки | Super+I |
| Блокировка | Super+L |
| Скриншот экрана / области | Print / Shift+Print |
| Смена рабочего стола | Ctrl+Super+Left / Right |

Настройки пользователя хранятся в `~/.config/plume/`.
